# Regression Test Data

This directory contains the deterministic regression datasets for PFX.

Each algorithm version owns its own dataset.

```
tests/data/
    v1/
    v2/
    ...
```

## Directory Structure

Each version contains:

- `input.csv` — Plaintext test inputs.
- `golden.csv` — Expected outputs generated by the corresponding algorithm version.
- `report.txt` — Verification report generated by the regression tool (temporary).

## Purpose

The regression dataset defines the deterministic contract of an algorithm version.

For the same input, the generated output must always be identical.

The regression tool compares newly generated outputs against the golden dataset.

If every entry matches, the implementation remains compatible with the current algorithm version.

If any output differs, the implementation must be reviewed.

## Versioning Rules

- Existing datasets must never be modified.
- Bug fixes and refactoring must preserve the existing golden dataset.
- Any intentional algorithm change requires a new dataset directory.

Example:

```
tests/data/
    v1/
    v2/
```

Do not overwrite `v1`.

Create a new dataset for `v2`.

## Dataset Categories

The input dataset should include representative plaintexts, such as:

- Basic ASCII
- Mixed Characters
- Long Text
- Unicode Latin
- Arabic
- Japanese
- Chinese
- Korean
- Cyrillic
- Emoji
- Edge Cases

The goal is to verify deterministic behavior across a wide variety of inputs.
